드론 지식을 매일 스스로 모으고, 정리하고, 발행하는 시스템

2nd Brain은 드론 분야의 논문·기술영상·뉴스·펌웨어 릴리즈를 AI가 매일 새벽 자동 수집하여 한국어 위키 문서로 정리하고, 문서 간 관계를 지식그래프로 연결한 뒤, 웹사이트(DroneWiki)로 발행하는 개인 지식 자동화 솔루션입니다. 사람은 방향만 정하고, 수집·요약·정리·발행은 시스템이 수행합니다.

2위키 문서 생성 — AI가 자료를 "지식"으로 정리

수집함(inbox)에 쌓인 원자료를 AI가 읽고, 정해진 규칙(스키마)에 따라 한국어 위키 문서로 변환합니다.

  1. 수집함 스캔그날 들어온 논문·영상·기사 원문을 AI가 전부 읽음
  2. 4계층 분류개념(Concepts) · 개체(Entities) · 비교(Comparisons) · 질의(Queries) 중 알맞은 유형으로 작성
  3. 메타데이터 부여7개 도메인 분류 + 출처 + 신뢰도(confidence) + 태그를 문서 머리에 기록
  4. 상호 링크 연결관련 문서를 [[위키링크]]로 연결 — 이 링크가 지식그래프의 재료가 됨
  5. 기록과 보관목차(index)와 작업일지(log) 갱신, 처리한 원문은 증빙용으로 보관
사람의 역할 — 모든 문서는 confidence: high/medium/low로 신뢰도가 표시되며, 실전 경험으로 검증한 내용은 사람이 등급을 올립니다. AI가 쓰고, 사람이 보증하는 구조입니다.

3지식그래프 생성 — 문서를 "연결된 지식"으로

문서가 쌓이기만 하면 창고입니다. 문서 간 관계를 그래프로 만들어야 지식이 됩니다.

어떻게 만드나

각 문서의 메타데이터와 [[위키링크]]·태그를 자동 파싱해서, 문서=노드 · 관계=엣지인 그래프(JSON)를 생성합니다. 새 문서가 생길 때마다 자동 갱신됩니다.

눈으로 탐색

웹에서 인터랙티브 그래프로 시각화 — 도메인별 색상, 노드 클릭 시 해당 위키 문서로 이동합니다.

AI가 활용 (GraphRAG)

AI Q&A가 질문과 관련된 문서를 찾은 뒤 그래프에서 이웃 개념까지 확장해 답변 근거로 사용 — 단순 검색보다 맥락이 풍부한 답을 만듭니다.

정리

2nd Brain은 "수집 → 정리 → 연결 → 발행"의 지식 생산 사이클 전체를 자동화했습니다. 운영 비용은 API 무료 티어와 구독형 AI로 사실상 0원이며, 소스 추가는 설정 파일 한 줄이면 됩니다. 다음 단계는 국내 논문(KCI·ScienceON) 연동 완료와 지식그래프 클러스터 뷰 고도화입니다.
