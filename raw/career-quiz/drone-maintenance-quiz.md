## 문항

### Q106. 무인기 프로펠러 정비 시 가장 중요한 점검 항목은?
- ✅ 균열/파손 여부 및 밸런스 확인
-    색상 확인
-    재질 확인
-    브랜드 확인

**해설**: 균열·칩핑은 비행 중 파손으로 이어짐. 밸런스 불균형은 과도한 진동 발생 → IMU 오류. 두 가지가 정비 최우선 항목.

**팁**: 프롭 밸런서(propeller balancer) 사용법과 기준치(±0.1g 이내) 숙지 필수.

### Q107. BLDC 모터의 '권선 저항 측정'을 통해 알 수 있는 것은?
- ✅ 3상 코일 단선/단락 여부
-    배터리 잔량
-    ESC 상태
-    FC 상태

**해설**: 멀티미터로 3상(A-B, B-C, C-A) 저항을 측정. 값이 균일하면 정상, 하나가 크게 다르면 단선, 0Ω에 가까우면 단락.

**팁**: 정상 저항 범위: 기종마다 다르나 A-B=B-C=C-A 균일. 차이가 10% 이상이면 교체 검토.

### Q108. LiPo 배터리 팽창(부풀음) 발견 시 조치는?
- ✅ 즉시 사용 중단, 전용 처리 시설 폐기
-    충전 후 사용
-    천공하여 가스 제거
-    냉동 보관

**해설**: LiPo 팽창은 내부 화학 반응 이상, 가스 발생 신호. 계속 사용 시 화재·폭발 위험. 즉시 폐기, 무조건 사용 금지.

**팁**: 폐기 방법: 소금물에 방전 후 전용 폐배터리 수거함 반납. 절대 일반쓰레기 투기 금지.

### Q109. 무인기 정기점검 후 비행 전 반드시 수행해야 하는 것은?
- ✅ 지상 호버 테스트 및 제어 응답 확인
-    즉시 최고 고도 비행
-    정비 기록 미작성
-    보관 후 다음 비행

**해설**: 정비 후 첫 비행: 지상 저고도 호버링으로 진동·기울기·제어 응답 확인 필수. 이상 감지 시 추가 점검 후 비행.

**팁**: 정비 일지 작성 의무: 조종자가 운영하는 기체는 정비 이력 기록이 항공안전법상 권고.

### Q110. ESC(Electronic Speed Controller) 캘리브레이션이 필요한 경우는?
- ✅ 새 ESC 교체, 스로틀 범위 불일치, 비정상 모터 반응
-    매일 정기 실시
-    배터리 교체마다
-    FC 교체마다

**해설**: ESC는 FC에서 보내는 스로틀 신호(PWM/DSHOT) 범위를 학습. 새 ESC나 FC 교체, 비정상 반응 시 캘리브레이션으로 동기화.

**팁**: PX4는 DSHOT 프로토콜로 디지털 제어 시 캘리브레이션 불필요. PWM ESC는 반드시 캘리브 필요.

### Q711. LiPo 배터리의 장기 보관 시 권장되는 셀당 전압은?
-    3.0V (완전 방전)
- ✅ 3.7~3.85V (보관 전압)
-    4.2V (완전 충전)
-    4.35V (고전압 충전)

**해설**: LiPo 배터리 장기 보관 시 셀당 3.7~3.85V의 보관 전압(Storage Voltage)을 유지해야 한다. 완전 충전 상태(4.2V) 장기 보관은 배터리 팽창·수명 단축, 완전 방전(3.0V 이하) 보관은 불가역적 손상을 유발한다.

**팁**: 보관 전압 = 3.7~3.85V/셀, 충전기의 Storage 모드 활용

### Q712. 드론 모터에서 KV값(KV rating)의 의미는?
-    모터의 최대 전압 허용치(kV = kilovolt)
- ✅ 1V당 분당 무부하 회전수(RPM/V)
-    모터 코일의 저항값(옴)
-    최대 전류 용량(A)

**해설**: KV값은 모터에 1V를 인가했을 때 무부하(no load) 상태에서 분당 회전수(RPM)를 나타낸다. KV1000 모터에 12V를 인가하면 이론상 12,000RPM으로 회전한다. 높은 KV = 소형 고속 프로펠러, 낮은 KV = 대형 저속 프로펠러에 적합하다.

**팁**: KV = RPM/V, 높은 KV → 소형 고속, 낮은 KV → 대형 저속

### Q713. 드론 프로펠러 교체 기준으로 옳지 않은 것은?
-    육안으로 확인 가능한 균열 또는 칩(chip)이 발생한 경우
-    블레이드 팁이 뒤틀리거나 변형된 경우
-    추락 또는 물체와 충돌 후
- ✅ 사용 시간이 매우 짧더라도 색상이 약간 바랜 경우

**해설**: 프로펠러 교체 기준은 구조적 손상(균열·칩·변형)과 충돌 후 안전 확인 불가 시다. 단순 표면 색상 변화(자외선 변색 등)만으로는 교체 기준이 되지 않는다. 구조적 무결성이 핵심 판단 기준이다.

**팁**: 프로펠러 교체 = 구조 손상 기준, 색 변화는 교체 기준 아님

### Q714. 드론 수신기와 송신기 바인딩(Binding) 절차의 목적은?
-    배터리를 충전하기 위해
- ✅ 특정 수신기가 해당 송신기의 신호만 수신하도록 고유 쌍(pair)을 설정하는 과정
-    ESC와 모터의 회전 방향을 설정하기 위해
-    FC 펌웨어를 업데이트하기 위해

**해설**: 바인딩은 수신기를 특정 송신기의 고유 식별 코드에 연결하는 과정이다. 바인딩 후에는 해당 송신기의 신호만 수신하여 다른 송신기 간섭이나 오조종을 방지한다.

**팁**: 바인딩 = 송수신기 1:1 페어링, 타 송신기 간섭 차단

### Q715. 드론 정비에서 멀티미터(Multimeter)로 LiPo 배터리 셀 전압을 측정할 때 올바른 측정 설정은?
-    AC 전압(V~) 범위로 설정
- ✅ DC 전압(V⎓) 범위로 설정하며, 예상 전압보다 높은 범위를 선택
-    저항(Ω) 범위로 설정
-    전류(A) 범위로 설정

**해설**: 배터리는 직류(DC) 전원이므로 DC 전압 범위(V⎓)로 측정해야 한다. LiPo 셀은 최대 4.2V이므로 20V 또는 그 이상의 DC 전압 범위를 선택한다. AC 범위로 측정하면 부정확한 값이 나온다.

**팁**: 배터리 측정 = DC 전압 범위, 예상 전압보다 높은 범위 선택

### Q716. 드론 프레임 조립 시 랜딩기어의 주요 역할은?
-    모터와 프로펠러를 고정하는 역할
- ✅ 착지 충격을 흡수하고 기체 하부 부품(배터리, FC, 카메라)을 지면으로부터 보호하는 역할
-    GPS 신호를 수신하는 안테나 역할
-    배터리 전원을 분배하는 역할

**해설**: 랜딩기어는 착지 시 충격을 흡수(특히 진동 감쇄 기능 포함 제품)하고, 기체 하부에 장착된 배터리·FC·카메라 등 부품이 지면과 직접 접촉하지 않도록 이격 공간을 제공한다.

**팁**: 랜딩기어 = 충격 흡수 + 하부 부품 보호

### Q717. 드론 비행 후 점검에서 모터 온도 확인의 목적은?
-    모터 KV값 변화를 확인하기 위해
- ✅ 과열 여부를 확인하여 코일 절연 열화, 베어링 손상, 과부하 운용 여부를 판단하기 위해
-    배터리 충전 필요성을 확인하기 위해
-    프로펠러 균형 상태를 간접 확인하기 위해

**해설**: 비행 후 모터 온도가 과도하게 높으면 코일 절연 열화, 베어링 마모 가속, 과부하 운용 또는 냉각 불량을 의미한다. 손으로 확인하거나 IR 온도계로 측정하며, 일반적으로 60~80°C 이상이면 점검이 필요하다.

**팁**: 모터 온도 高 = 과열 징후 → 코일 절연·베어링·냉각 상태 점검

### Q718. 드론 전원 배선에서 XT60 커넥터와 T플러그(Dean's Plug)의 공통적인 특성은?
-    최대 5A 이하의 낮은 전류용으로 설계되었다
- ✅ 고전류(일반적으로 60A 이상) 드론 전력 연결에 적합한 양극·음극 분리 구조의 커넥터다
-    주로 신호(PWM/데이터) 연결에 사용된다
-    충전 전용으로 방전 연결에는 사용하지 않는다

**해설**: XT60은 순간 최대 120A, 지속 60A 정격의 고전류 배터리 연결용 커넥터다. T플러그(Dean's Plug)도 최대 50~60A 정격의 고전류 커넥터다. 두 제품 모두 드론 배터리-전력 분배(PDB) 연결에 널리 사용된다.

**팁**: XT60·T플러그 = 고전류(60A+) 배터리 연결 전용 커넥터

### Q719. 드론 비행 제어기(FC) 펌웨어 업데이트 시 반드시 사전에 수행해야 하는 작업은?
-    배터리를 완전히 방전시킨 후 업데이트한다
- ✅ 현재 설정값(파라미터)과 캘리브레이션 데이터를 백업한다
-    모든 모터를 분리한 후 업데이트한다
-    GPS 수신기를 분리한 후 업데이트한다

**해설**: 펌웨어 업데이트 시 기존 파라미터 설정이 초기화될 수 있으므로, 업데이트 전 현재 파라미터와 캘리브레이션 값을 GCS 소프트웨어로 백업해야 한다. 업데이트 후 백업 파일을 복원하거나 재캘리브레이션을 진행한다.

**팁**: 펌웨어 업데이트 전 = 파라미터 백업 필수

### Q720. 드론 조립 후 처음 시동 시 ESC 캘리브레이션이 필요한 이유는?
-    배터리 용량을 ESC에 등록하기 위해
- ✅ 송신기의 스로틀 최댓값·최솟값을 ESC가 인식하도록 동기화하여 정확한 모터 제어 범위를 설정하기 위해
-    프로펠러 균형을 맞추기 위해
-    FC와 GPS 신호를 동기화하기 위해

**해설**: ESC 캘리브레이션은 송신기 스로틀의 최대(PWM 최고값)와 최소(PWM 최저값)를 ESC에 학습시켜, 스로틀 범위 전체를 정확히 활용하도록 하는 작업이다. 미실시 시 모터 응답 범위 불일치로 비행이 불안정해진다.

**팁**: ESC 캘리브 = 스로틀 최대·최소값 학습, 신규 조립·송신기 교체 시 필수

### Q721. BLHeli_32 ESC의 '디마자(Dshot)' 프로토콜이 기존 아날로그 PWM 대비 갖는 장점은?
-    배터리 소모를 50% 절감한다
- ✅ 디지털 신호 전송으로 외부 간섭에 강하고, 빠른 응답 속도와 텔레메트리(RPM·전류·온도) 피드백이 가능하다
-    별도의 캘리브레이션 없이 자동 설정된다
-    아날로그 PWM보다 신호 전송 거리가 2배 길다

**해설**: Dshot(Digital Shot)은 디지털 프로토콜로, 아날로그 PWM의 노이즈·캘리브레이션 오차 문제를 해결하며, Dshot300/600/1200 등 버전에 따라 응답 속도가 매우 빠르다. BLHeli_32에서는 ESC 텔레메트리(RPM, 온도, 전류)를 FC로 피드백할 수 있다.

**팁**: Dshot = 디지털 → 간섭 강하 + 빠른 응답 + ESC 텔레메트리 지원

### Q722. 드론 모터 코일 저항 측정 시 불균형 저항이 발견되었을 때의 의미와 조치는?
-    코일 저항 불균형은 정상이며 조치 불필요하다
- ✅ 코일 단락(short) 또는 단선(open)을 의미하며, 해당 모터는 교체해야 한다
-    ESC 설정을 변경하면 보정된다
-    프로펠러를 교체하면 해결된다

**해설**: 3상 BLDC 모터에서 각 상(U·V·W)의 코일 저항은 균일해야 한다. 불균형이 있다면 코일 단락(단락 시 저항 감소) 또는 단선(단선 시 저항 무한대)을 의미하며, 이 상태로 운용하면 과열·불균등 토크·진동·모터 소손이 발생한다.

**팁**: 코일 저항 불균형 = 단선/단락 → 모터 교체

### Q723. 드론 LiPo 배터리 'C 레이팅(C Rating)'의 의미와 활용 방법은?
-    배터리의 셀 수(셀 직렬 연결 수)를 나타낸다
- ✅ 배터리 용량 대비 최대 방전율을 나타내며, 최대 방전 전류(A) = 용량(Ah) × C 레이팅으로 계산한다
-    배터리의 충전 사이클 수명을 나타낸다
-    배터리 내부 저항(mΩ)을 나타낸다

### Q741. 드론 모터에서 BLDC(Brushless DC) 모터의 'Stator Winding 결선 방식' 중 델타(Δ) 결선 대비 Y(스타) 결선의 특성은?

- ✅ Y 결선은 델타 결선 대비 같은 전압에서 토크가 크고 RPM이 낮아 대형 프로펠러 저속 구동에 유리하며, 델타 결선은 같은 전압에서 RPM이 높아 소형 고속 프로펠러에 적합하다
-    Y 결선과 델타 결선은 전기적으로 등가이므로 실제 모터 성능 차이가 없으며 제조사가 생산 편의에 따라 결선 방식을 선택할 뿐 KV나 토크는 동일하다
-    Y 결선은 중성점 전류가 델타보다 루트3(√3)배 높아 코일 발열이 심하고 고온 운용 시 절연 파괴 위험이 크므로 방제·방산 드론에 부적합하다

**해설**: Y 결선은 각 상 코일이 직렬로 더 긴 경로를 형성하여 등가 저항이 높고 동일 전압에서 전류가 낮아 토크형(저KV·고토크). 델타 결선은 코일이 병렬로 연결되어 낮은 임피던스 → 고RPM형(고KV·저토크). Y 결선이 대형 드론·방제 헬기에 적합하다.

**팁**: Y 결선 = 저KV·고토크 (대형 저속) / 델타 결선 = 고KV·저토크 (소형 고속)

### Q742. 드론 FC의 ArduPilot/PX4 비행 로그(DataFlash/ULog) 분석에서 'RCIN' 채널과 'RCOUT' 채널의 차이는?
-    RCIN과 RCOUT은 FC 내부에서 동일한 PWM 신호를 공유하는 채널이므로 두 채널의 데이터는 항상 동일한 값을 나타내며, 비교 분석보다는 통합 채널로 단일 로그에 기록한다
- ✅ RCIN은 수신기에서 FC로 들어오는 조종자 입력 값, RCOUT은 FC에서 ESC/서보로 나가는 제어 명령 값이다. 두 채널의 비교를 통해 FC 제어 로직이 정상 작동하는지 확인할 수 있다
-    RCIN은 FC 내장 GPS 수신기가 위성으로부터 수신하는 항법 신호 채널로, NMEA 문장과 원시 의사거리 데이터를 포함하며 RCOUT과는 완전히 다른 물리 계층의 신호이다
-    RCOUT은 FC에서 배터리 모니터링 IC로 전달되는 셀 전압·전류 데이터 패킷으로, ADC 원시값을 UART로 출력하여 지상 텔레메트리로 실시간 배터리 상태를 전송하는 채널이다

**팁**: RCIN = 조종자 입력, RCOUT = FC 출력, 비교 분석으로 제어 로직 진단

### Q748. 드론 전원 시스템에서 'BEC(Battery Eliminator Circuit)'의 역할과 선형 BEC 대비 스위칭 BEC의 장점은?

- ✅ BEC는 메인 배터리 전압을 서보·FC·수신기에 맞는 5V로 변환하는 장치이며, 스위칭 BEC는 선형 BEC보다 효율이 높아 발열이 적고, 고전압 입력에서도 안정적으로 동작한다
-    BEC는 FC 전원이 차단될 때 커패시터 에너지로 서보를 일시 구동하는 장치이며, 스위칭 방식은 선형 방식보다 커패시터 용량이 커서 정전 유지 시간이 긺
-    선형 BEC는 트랜지스터 포화 영역으로 정전압을 출력하여 RF 노이즈가 없고 스위칭 BEC는 MOSFETs PWM 제어 방식으로 효율이 높아 용도별로 선택

**해설**: 선형 BEC는 초과 전압을 열로 소산하여 효율이 낮고(특히 입력 전압이 높을수록 발열 심함). 스위칭 BEC는 고주파 스위칭으로 전압을 변환하여 효율이 높고(85~95%), 발열이 적으며, 고전압 배터리 드론에 필수적이다. 단, RF 노이즈 필터링이 필요할 수 있다.

**팁**: 스위칭 BEC = 고효율·저발열, 선형 BEC = 저노이즈·저효율

### Q749. 드론 정기 점검 주기 기준에서 비행 시간(Flight Hours) 기반 정비와 비행 횟수(Cycle) 기반 정비를 병행해야 하는 이유는?
-    항공법 시행규칙과 무인비행장치 안전성 인증 고시에서 비행 시간과 비행 횟수 모두를 정비 이력 일지에 의무적으로 기록하도록 법령으로 명문화하고 있으므로, 두 방식을 모두 병행하여 기록해야만 관련 법적 요구사항이 충족된다
- ✅ 비행 시간만으로는 이착륙(기계적 충격·진동) 누적 손상을 반영하지 못하고, 비행 횟수만으로는 장시간 연속 운전에 의한 열화를 반영하지 못하므로, 두 기준 중 먼저 도달하는 조건에서 점검을 실시하는 '조건 선행(Whichever Comes First)' 방식이 가장 안전하다
-    비행 시간 기반과 비행 횟수 기반 정비는 각각 추적하는 부품 수명 지표가 서로 다르지만, 실제로 진행되는 세부 점검 항목 목록과 교환 대상 부품의 종류와 수량이 완전히 동일하므로 두 방식을 병행해도 추가 안전 이점은 없다
-    리튬 폴리머 배터리의 총 충방전 사이클 수가 모터·ESC·메인 프레임·암·랜딩기어 등 드론의 모든 구조 부품 피로 수명을 대표하는 단일 통합 수명 지표이므로, 배터리 교체 주기만으로도 전체 드론의 정기 점검 시기를 결정할 수 있다

**해설**: 이착륙 횟수는 랜딩기어·암·프레임의 충격 누적을 반영하며, 비행 시간은 모터·ESC·배터리의 열화와 직결된다. 두 기준을 병행하여 먼저 도달하는 시점에 점검하면 예방 정비의 효과를 극대화할 수 있다.

**팁**: 비행시간 + 횟수 병행 = 열화·충격 모두 반영, 먼저 도달한 기준으로 점검

### Q750. 드론 항공기 등록 및 보험 갱신 절차에서 최대이륙중량(MTOW) 2kg 초과 드론의 의무 사항으로 옳은 것은?
-    최대이륙중량 2kg 초과 드론은 조종자 자격증 취득 전까지 모든 공역에서 비행이 금지되며, 자격증 취득 후에도 관제권 내 비행은 전면 제한된다
- ✅ 지방항공청에 기체 신고(등록) 의무가 있으며, 보험 가입(제3자 배상책임보험)이 의무화되어 있고, 조종자 자격증 취득이 필요하다. 미준수 시 과태료 부과 대상이다
-    최대이륙중량 2kg 초과 드론은 국토교통부 형식 증명을 받은 기종만 허가되며, 미인증 기종은 항공사와 별도 운항 협약을 체결해야 비행 가능하다
-    2kg 초과 드론의 보험 가입은 권고 사항이며 기체 신고 후 비행 승인 신청만으로 공역 사용이 가능하고 사고 발생 시 개인 배상으로 처리된다

**해설**: 항공안전법에 따라 최대이륙중량 2kg 초과(일부 규정에서는 250g 초과) 드론은 지방항공청 신고, 제3자 배상책임보험 가입, 해당 무게 등급에 맞는 조종자 자격증 취득이 의무다. 보험 갱신 만료 전 재가입해야 비행 자격이 유지된다.

**팁**: 2kg 초과 드론 의무 3종: 기체 신고 + 보험 가입 + 조종자 자격증

### Q751. 드론 정비에서 토크렌치(Torque Wrench) 사용이 중요한 이유와 과소 토크/과도 토크 각각의 문제점은?
-    토크렌치는 조립 속도를 높이기 위한 도구로, 정확한 토크보다 빠른 조립이 우선이다
- ✅ 과소 토크는 볼트 풀림에 의한 비행 중 구조 분리 위험, 과도 토크는 볼트·나사산 손상 및 탄소섬유 프레임 파손 위험이 있어, 제조사 지정 토크값 준수가 필수다
-    모든 볼트는 최대한 강하게 조이는 것이 안전하다
-    드론에서는 토크렌치가 필요 없으며 손으로 조이는 것으로 충분하다

**해설**: 드론 구조 볼트(암·모터 마운트·랜딩기어)는 과소 토크 시 비행 중 진동으로 풀려 구조 분리 사고를 초래한다. 과도 토크는 카본 프레임의 층간 박리(delamination)나 나사산 파손을 유발한다. 제조사 지정 토크값(Nm)을 토크렌치로 정확히 적용해야 한다.

**팁**: 토크렌치 = 제조사 지정 Nm 준수, 과소→풀림·과도→파손

### Q752. 드론 FC 보드의 '자이로스코프(Gyroscope)' 노이즈 필터링 설정(Notch Filter, Low-pass Filter)이 비행 성능에 미치는 영향은?
-    자이로 필터 설정은 PID 게인 스케일링 로직과 완전히 독립적으로 동작하므로, 제조사 기본값을 유지하더라도 기체 하중 변화, 프로펠러 교체, 모터 마모 정도에 관계없이 항상 최적의 진동 감쇠가 자동으로 유지된다
- ✅ 노치 필터는 모터 회전 주파수와 그 배수 주파수의 노이즈를 선택적으로 제거하고, 저역통과 필터는 고주파 노이즈를 전반적으로 억제하여 PID 제어 품질을 높이지만, 과도한 필터링은 제어 지연(latency)을 증가시켜 응답성을 저하시킨다
-    자이로 노치 필터 감쇠 폭(bandwidth)과 저역통과 필터 차단 주파수를 모두 최저값으로 설정하면 PID 입력 신호에서 모든 주파수 노이즈 성분이 완전히 제거되어 항상 최대의 비행 안정성이 달성된다
-    자이로스코프 필터 설정은 EKF 내부의 가속도·자이로 센서 융합 가중치 계수에만 영향을 주므로 GPS 항법 위치 정확도와 직접 연관되며, 비행 제어 PID 루프의 응답 특성 및 진동 억제와는 무관하다

**해설**: 노치 필터는 모터/프로펠러의 특정 주파수 진동만 선택적으로 제거하여 PID 오차 신호의 노이즈를 줄인다. 저역통과 필터는 전반적 고주파 억제. 그러나 필터가 너무 강하면 제어 신호 자체가 지연되어 응답성이 나빠지므로 적절한 균형이 중요하다.

**팁**: 노치 필터 = 특정 주파수 제거 / LP 필터 = 전반적 고주파 억제 → 과도 필터링 = 응답 지연

### Q753. 드론 방수 실링(Sealing) 처리 후 누수 검사 방법으로 가장 적합한 것은?
-    방수 처리 후 기압 변화 테스트를 수행하여 실링 부위의 기밀성을 확인하고 질소 가스를 주입하여 내부 압력 변화가 없으면 방수 처리가 적절히 완료된 것
- ✅ IP 등급 기준에 따라 해당 수준의 분사 시험(IPX4~IPX6) 또는 침수 시험(IPX7+)을 실시하고, 전원 OFF 상태에서 검사 후 건조 확인 후 전원을 투입한다
-    형광 염료를 첨가한 물을 드론 외부에 분무한 뒤 자외선 조명으로 전체 기체를 스캔하여 틈새나 커넥터 주변의 염료 침투 흔적으로 누수 경로를 탐지
-    드론 내부에 습도 센서를 임시 장착하고 설계 강수 조건에 해당하는 온도·습도 챔버에 24시간 보관하여 내부 습도 상승 여부로 방수 성능을 정량 평가

**해설**: 방수 처리 후 검증은 목표 IP 등급의 시험 방법(분사 강도·방향·시간, 침수 깊이·시간)을 준수하여 실시한다. 반드시 전원 OFF 상태에서 검사하고, 이후 완전 건조를 확인한 뒤 통전 시험을 한다.

**팁**: 방수 검사 = IP 기준 시험(분사/침수) + 전원 OFF → 건조 확인 후 통전

### Q754. 드론 FC에서 'Brownout'(순간 전압 강하) 오류가 발생하여 비행 중 재부팅이 일어난 원인과 예방 방법은?
-    FC Brownout 오류는 GPS 위성 가시 개수가 안전 임계치 이하로 감소하여 EKF 항법 해가 완전히 발산할 때, 비행 컴퓨터가 내부 안전 정지 루틴을 강제 실행하여 의도적으로 시스템을 재부팅하는 보호 동작이다
- ✅ 배터리 전압이 순간적으로 FC 동작 전압 이하로 떨어져 재부팅이 발생하며, 원인은 내부 저항이 높은 배터리·불충분한 필터링 커패시터·FC 전원 회로 불량이다. 배터리 교체, 전원 라인 커패시터 추가, 별도 FC 전원 공급 회로 개선으로 예방한다
-    Brownout은 안테나 다이버시티 고속 스위칭 과정에서 두 수신 안테나 경로에 유도된 강한 GPS 신호가 FC 내부 RF 회로에 과도한 전자기 유도 전압을 일으켜 CPU 클럭을 교란하고 재부팅을 유발하는 현상이다
-    FC Brownout은 비행 중 급격한 자세 변화로 FC 실시간 제어 루프 계산량이 MCU 최대 처리 용량을 순간 초과하여 하드웨어 내장 워치독 타이머가 응답 시간 초과를 감지하고 강제 재부팅을 실행하는 오류다

**해설**: Brownout은 고전류 부하(모터 급가속) 시 배터리·전원 회로의 순간 전압 강하로 FC 공급 전압이 최소 동작 전압 아래로 떨어져 FC가 재부팅되는 현상이다. 전원 라인에 커패시터 추가, BEC 용량 증설, 신선한 배터리 사용으로 예방한다.

**팁**: Brownout = 순간 전압 강하 → 커패시터 추가 + 배터리·BEC 점검

### Q755. 드론 정비사가 모터 교체 후 반드시 확인해야 하는 '모터 회전 방향'과 '프로펠러 방향'의 관계로 옳은 것은?
-    모터의 회전 방향은 ESC 소프트웨어로 역전 설정이 가능하므로 프로펠러 피치 방향과 독립적으로 제어할 수 있어, 어떤 프로펠러를 장착해도 ESC 방향 설정만 조정하면 정상 양력이 발생한다
- ✅ 쿼드콥터 기준, 각 모터의 회전 방향(CW/CCW)에 맞는 프로펠러(정회전/역회전 날개 형상)를 장착해야 한다. 회전 방향과 프로펠러 형상이 불일치하면 양력 대신 하강력이 발생하여 이륙이 불가능하다
-    X-프레임 쿼드콥터의 4개 모터는 롤·피치·요 제어를 위해 모두 동일한 CW 방향으로 회전하며, 반토크 상쇄는 모터 속도 차이(차동 추력)로만 구현하는 것이 표준 설계다
-    프로펠러는 대칭 익형 구조로 제작되어 CW 또는 CCW 어느 방향으로 회전해도 에어포일 압력 분포가 동일하게 형성되어 동등한 크기의 양력 또는 하강력을 발생시킨다

**해설**: 쿼드콥터의 각 모터는 정해진 방향(CW/CCW)으로 회전하며, 이에 맞는 프로펠러(정방향 피치/역방향 피치)를 장착해야 위쪽 방향의 양력이 발생한다. 반대로 장착하면 아래 방향 힘이 발생한다. 모터 교체 후 회전 방향 확인과 프로펠러 방향 매칭이 필수다.

**팁**: CW 모터 → CW 프로펠러, CCW 모터 → CCW 프로펠러 (방향 일치 필수)

### Q756. 드론 FPV 시스템에서 '영상 끊김(Video Dropout)' 현상의 원인과 점검 순서로 옳은 것은?
-    FPV 카메라 렌즈 표면의 이물질·지문이 빛을 산란시켜 수신 신호 품질 지표(RSSI)를 저하시키고 영상 끊김의 가장 빈번한 원인이 된다
- ✅ VTX 채널/주파수 충돌 → 전파 장애물(카본 차폐) 확인 → VTX 출력 전압 불안정 → 안테나 연결 불량 → VTX/수신기 하드웨어 불량 순서로 점검한다
-    FPV 영상 끊김은 LiPo 셀 불균형으로 전압 강하 발생 시 VTX 공급 전압이 최소 동작 전압 이하로 떨어져 나타나므로 배터리 교체로 해결된다
-    RC 수신기 채널이 VTX 주파수와 혼변조 간섭 대역에 있을 때 영상이 끊기므로 RC 운용 주파수를 변경하면 간섭이 해소되어 해결된다

**해설**: FPV 영상 끊김 점검 순서: ① 채널·주파수 충돌 확인 → ② 안테나 방향·장착 상태 → ③ 카본 프레임에 의한 차폐 → ④ VTX 전원 전압 측정(5V 안정 여부) → ⑤ 안테나 커넥터 접촉 → ⑥ VTX·수신기 하드웨어 불량 판단. 소프트웨어·전원·하드웨어 순으로 점검하는 것이 효율적이다.

**팁**: FPV 끊김 점검: 채널 충돌 → 안테나 상태 → 전원 전압 → 하드웨어 순서

### Q757. 드론 FC의 '페일세이프(Failsafe)' 설정에서 RC 신호 손실 시 'RTH(Return to Home)'를 선택하는 경우와 '자동 착륙(Land)'을 선택하는 경우의 차이점은?
-    RTH와 자동 착륙은 페일세이프 트리거 조건, 비행 경로 생성 알고리즘, GPS 요구사항, 지형 위험도 모두 동일하며 단지 UI 명칭만 다른 같은 동작을 서로 다른 펌웨어 버전에서 부르는 것이다
- ✅ RTH는 홈 포인트(이륙 지점)로 귀환 후 착륙하므로 GPS가 정상일 때 유효하며, 자동 착륙은 현재 위치에서 바로 수직 하강 착륙하므로 GPS 없이도 작동하나 현재 위치 지형에 따라 위험할 수 있다
-    RTH는 홈 포인트까지 경로 계획이 필요하여 GPS 오류 시 위험하고, 자동 착륙은 GPS 없이도 기압 고도와 광류 센서만으로 정밀하게 작동하므로 GPS 상태와 무관하게 항상 더 안전하다
-    자동 착륙은 바로미터·광류·레이저 고도계 센서 데이터를 융합하여 수직 강하 위치를 정밀 보정하므로 홈 포인트 GPS 좌표를 사용하는 RTH보다 항법 정확도가 구조적으로 더 높다

**해설**: RTH: GPS 의존, 이륙 지점으로 귀환 → GPS 정상 시 유리. 자동 착륙: 현재 위치 수직 하강 → GPS 없이 가능하나 현재 위치가 안전한 착지 장소인지 불명확. 비행 구역과 GPS 상태를 고려하여 적절한 페일세이프를 선택해야 한다.

**팁**: RTH = GPS 의존 귀환, 자동 착륙 = 현위치 즉시 착륙 (GPS 불필요)

### Q758. 드론 암(Arm)의 피로 균열을 조기 감지하기 위한 비파괴 검사(NDT) 방법 중 현장에서 가장 실용적인 방법은?
-    X선 투과 검사(Radiographic Testing)가 카본 섬유 복합재의 층간 박리를 정확히 탐지하는 유일한 검사법이며, 현장 이동형 X선 장비를 통해 드론 정비 현장에서도 표준 NDT로 적용된다
- ✅ 육안 검사(균열·변색 확인) + 두드림(tap) 검사(탄소섬유 계층 박리 시 탁한 음질 변화 감지) + 초음파 두께 측정(박리 확인)을 조합하여 현장에서 비파괴적으로 검사할 수 있다
-    항공우주 등급 탄소 섬유 복합재는 유리섬유와 달리 내피로 특성이 뛰어나 수천 회 이착륙 사이클에서도 균열·박리가 발생하지 않으므로 구조 건전성 NDT 점검 대상에 포함되지 않는다
-    카본 암 피로 균열은 탄소 섬유의 도전성 저하로 나타나므로 사지 두 끝에 테스터기를 접촉하여 저항값을 측정하면 균열 위치와 박리 깊이를 정량적으로 진단할 수 있다

**해설**: 현장 NDT: ① 육안 검사(표면 균열·흰색 분말·변색 확인), ② 탭 테스트(손가락/동전으로 두드려 탁한 음질 변화로 층간 박리 감지), ③ 초음파 탐상기(박리 깊이·범위 확인). 이 3가지 방법을 조합하면 실험실 장비 없이도 상당한 신뢰도로 피로 균열을 감지할 수 있다.

**팁**: 현장 NDT: 육안 + 탭 테스트 + 초음파 조합 → 카본 피로 균열 감지

### Q759. 드론 정비 시 사용하는 '오실로스코프'가 멀티미터와 다르게 측정할 수 있는 정보는?
-    멀티미터보다 입력 임피던스가 10배 이상 높아 신호 계통에 부하를 거의 주지 않으므로, 고임피던스 센서나 I2C 버스의 실제 전압을 정확히 측정 가능
- ✅ 신호의 파형(파형 형태·주파수·듀티사이클·노이즈·글리치)을 시간축으로 시각화하여 확인할 수 있어, PWM 신호 품질·ESC 응답·통신 버스 파형 등을 진단할 수 있다
-    AC와 DC 전압을 동시에 측정하여 전원 공급부의 리플 전압 크기를 정량 분석할 수 있어, ESC 전원단 커패시터 용량 적정성 검증에 멀티미터보다 적합
-    두 채널 동시 측정으로 I2C SDA·SCL 신호를 함께 캡처하여 ACK/NACK 비트 수준의 통신 오류를 직접 확인하고 슬레이브 응답 지연을 정밀 측정 가능

**해설**: 멀티미터는 정적 또는 평균 전압·전류·저항을 측정하지만, 신호의 시간적 변화를 볼 수 없다. 오실로스코프는 신호 파형을 시간축으로 표시하여 PWM 신호의 펄스폭·주파수·글리치·노이즈를 직접 확인할 수 있어 드론 신호 계통 정밀 진단에 필수적이다.

**팁**: 오실로스코프 = 시간축 파형 시각화 → PWM·통신 신호 정밀 진단

### Q760. 드론 정비사 실무에서 '모터 스핀 방향 확인 테스트' 시 절대 해서는 안 되는 행동은?

-    BLHeli Configurator에서 소프트웨어로 모터 방향을 확인하는 것
