### Q21. Reynolds Boids 모델의 3가지 규칙은?
- ✅ Separation, Alignment, Cohesion
-    Attack, Defend, Retreat
-    Takeoff, Cruise, Land
-    Sense, Plan, Act

**해설**: Separation(분리: 충돌 회피), Alignment(정렬: 같은 방향), Cohesion(결합: 무리 중심으로 이동). 이 세 가지 단순 규칙으로 복잡한 군집 행동이 창발됩니다.

**팁**: 각 규칙의 가중치 조절이 군집 형태에 미치는 영향을 시각적으로 설명하세요.

### Q22. 중앙집중식과 분산 제어의 핵심 차이는?
- ✅ GCS 전체 제어 vs 각 드론 자율+이웃 통신
-    속도 차이
-    비용 차이
-    크기 차이

**해설**: 중앙집중: GCS가 모든 드론의 경로/임무를 직접 계산·지시. 분산: 각 드론이 이웃과 통신하며 자율적으로 판단. 실전에서는 계층적 하이브리드가 많습니다.

**팁**: 100대 규모에서 중앙집중의 한계(통신 병목, 단일장애점)와 분산의 어려움(합의 수렴 시간)을 비교하세요.

### Q23. 100대 드론의 안전한 이륙 전략은?
- ✅ 구역별 순차 이륙 (Zone-based Sequential)
-    전체 동시 이륙
-    랜덤 순서 이륙
-    고도별 이륙

**해설**: 지상을 구역으로 나누어 구역별로 순차 이륙하며, 각 구역 내에서도 충돌 회피 간격을 유지합니다. 이륙 후 대기 고도로 상승하여 대형 진입.

**팁**: 실제 100대 이륙 시퀀스 설계 경험, 시간 계산, 배터리 관리 방법을 구체적으로 설명하세요.

### Q24. Consensus Algorithm의 주요 목적은?
- ✅ 공유 상태에 대한 합의 도달
-    데이터 암호화
-    속도 최적화
-    배터리 절약

**해설**: 분산 시스템에서 모든 노드가 동일한 상태(예: 대형 변경, 임무 재할당)에 합의하기 위한 알고리즘입니다. Raft, PBFT 등이 대표적.

**팁**: 드론 군집에서 합의 알고리즘의 실시간 제약 조건과 통신 지연 영향을 설명하세요.

### Q25. ORCA 충돌 회피 알고리즘의 핵심 원리는?
- ✅ 책임 50% 분담, 최소 속도 변경
-    장애물 완전 정지
-    경로 재계획
-    고도 분리

**해설**: ORCA(Optimal Reciprocal Collision Avoidance)는 두 에이전트가 충돌 회피 책임을 50%씩 분담하며, 각자 최소한의 속도 변경으로 회피합니다.

**팁**: ORCA의 수학적 기반(Velocity Obstacle)과 실시간 성능 특성을 설명할 수 있으면 좋습니다.

### Q26. GPS RTK를 군집 라이트쇼에 사용하는 이유는?
- ✅ cm급 정밀도로 밀집 대형 가능
-    저렴해서
-    배터리 절약
-    통신 불필요

**해설**: RTK GPS는 ±2cm 정밀도를 제공하여 드론 간 1~2m 간격의 밀집 대형을 안전하게 유지할 수 있습니다. 일반 GPS(±2m)로는 불가능합니다.

**팁**: RTK 기지국 설치, 보정 데이터 전송, 수렴 시간 등 실무 경험을 언급하세요.

### Q27. Graceful Degradation이란?
- ✅ 일부 실패 시 나머지가 임무 재분배
-    전체 시스템 정지
-    실패 드론 폭파
-    백업 드론 투입만

**해설**: 드론 일부가 고장/이탈해도 나머지 드론이 자동으로 대형을 재구성하고 임무를 재분배하여 전체 임무를 계속 수행합니다.

**팁**: 100대 중 10% 이탈 시의 대형 재구성 알고리즘과 성능 저하 곡선을 설명하세요.

### Q28. 계층적 Swarm 아키텍처의 구조는?
- ✅ GCS → 편대장(Leader) → 개별 드론
-    모든 드론이 GCS와 직접 통신
-    드론 간 P2P만
-    클라우드 기반

**해설**: GCS가 편대장 드론에게 고수준 명령 → 편대장이 소속 드론에게 세부 명령. 통신 부하 분산과 확장성 확보의 핵심 아키텍처.

**팁**: 계층 수, 편대 크기, 편대장 선출/교체 메커니즘을 구체적으로 설명하세요.

### Q29. 대규모 드론 Task Allocation은 어떤 최적화 문제인가?
- ✅ mTSP / VRP (차량 경로 문제)
-    정렬 알고리즘
-    검색 알고리즘
-    압축 알고리즘

**해설**: 다수 드론에 다수 임무를 최적 할당하는 문제는 mTSP(다중 외판원) 또는 VRP(차량 경로 문제)로 모델링됩니다. NP-hard이므로 휴리스틱/메타휴리스틱 사용.

**팁**: 실제 사용한 최적화 알고리즘(Genetic Algorithm, Auction-based 등)과 계산 시간 제약을 설명하세요.

### Q30. GPS-denied 환경 대응이 아닌 것은?
- ✅ GPS 안테나 크기 확대
-    Visual SLAM
-    UWB 측위
-    관성 항법 보강

**해설**: GPS 안테나 크기를 키워도 GPS 신호 자체가 차단/재밍되면 무의미합니다. Visual SLAM, UWB, INS 보강이 실제 대안입니다.

**팁**: 각 대안의 장단점과 적용 환경을 비교 설명하세요.

### Q73. Virtual Structure 기법이란?
- ✅ 군집 전체를 가상 강체로 모델링하여 대형 유지

-    가상 드론 추가
-    홀로그램 대형

**해설**: Virtual Structure는 군집 전체를 하나의 가상 강체(Rigid Body)로 취급하여, 강체의 이동/회전으로 대형을 유지하면서 이동합니다.

**팁**: Virtual Structure vs Behavior-based vs Leader-Follower 접근법을 비교하세요.

### Q79. 군집 드론의 시간 동기화가 중요한 이유는?
- ✅ 협조적 동작(동시 이동/점멸)과 TDMA 통신을 위해
-    배터리 절약
-    속도 향상
-    보안

**해설**: 라이트쇼의 동시 점멸, 대형 전환의 동기화, TDMA 통신의 슬롯 타이밍 등 모든 협조적 동작에 정밀한 시간 동기화(μs 수준)가 필수입니다.

**팁**: GPS PPS, NTP, PTP(IEEE 1588) 등 시간 동기화 방법과 정밀도를 비교하세요.

### Q261. 드론 군집 비행에서 '분산 제어(Decentralized Control)' 방식의 가장 큰 장점은?
-    단일 마스터 노드가 전체 경로를 최적화할 수 있다
- ✅ 개별 노드 고장 시 전체 시스템 붕괴가 없어 내결함성이 높다
-    통신 지연이 없어 실시간 동기화가 완벽하다
-    중앙 서버에서 모든 드론 상태를 실시간 감시할 수 있다

**해설**: 분산 제어 방식은 각 드론이 자율적으로 판단하므로 단일 노드 고장이 전체 시스템에 영향을 주지 않아 내결함성(Fault Tolerance)이 높다. 반면 중앙집중형은 단일 실패 지점(SPOF) 문제가 있다.

**팁**: 분산 제어 = 내결함성↑, 중앙집중 = 전역 최적화↑. 방산 군집에서는 내결함성이 핵심 요구사항이다.

### Q262. 편대 비행 포메이션 중 전방 정찰·탐색 임무에 가장 유리한 V형 편대의 특징으로 옳은 것은?
-    전방 드론이 후방 드론의 후류(Wake)를 차단해 에너지 효율을 낮춘다
- ✅ 선두 드론이 기류를 가르고 후방 드론이 와류(Vortex) 양력을 활용해 에너지 효율이 높다
-    모든 드론이 동일 고도를 유지해 충돌 위험이 없다
-    후방 드론일수록 더 넓은 화각으로 영상 수집이 가능하다

**해설**: 철새 V형 편대처럼 선두 드론이 만든 와류(Upwash)를 후방 드론이 활용하면 양력 증가로 에너지 효율이 약 15~30% 향상된다. 군집 드론 설계 시 에너지 절감 포메이션으로 자주 채택된다.

**팁**: V형 편대 = 에너지 효율(와류 활용). 라인 편대 = 단순 전진. 다이아몬드 = 방어적 커버리지.

### Q263. 군집 드론에서 Leader-Follower 알고리즘의 팔로워 드론 제어 방식으로 가장 적합한 설명은?
- ✅ 팔로워는 리더의 위치와 속도를 추종하며 일정 오프셋을 유지한다
-    팔로워는 독립적으로 경로계획을 수행하고 리더와 합류한다
-    팔로워는 리더의 명령이 없으면 제자리에서 호버링한다
-    팔로워는 리더와 동일한 GPS 좌표로 이동한다

**해설**: Leader-Follower에서 팔로워는 리더의 위치·속도 정보를 수신하고, 사전 정의된 오프셋(거리·방위각)을 유지하며 추종한다. 이를 통해 포메이션 형상이 유지된다.

**팁**: Leader-Follower: 팔로워 = 리더 위치 + 고정 오프셋. Consensus: 모든 노드가 이웃 정보로 합의.

### Q264. Mesh 통신 토폴로지를 군집 드론에 적용할 때 주요 장점은?
-    단일 허브를 통해 모든 통신을 중계하므로 지연이 최소화된다
- ✅ 노드 간 다중 경로가 존재해 일부 노드 탈락 시에도 통신이 유지된다
-    모든 드론이 동일한 채널을 사용해 간섭이 없다
-    토큰을 순환시켜 공평한 채널 접근을 보장한다

**해설**: Mesh 토폴로지는 노드 간 다중 경로를 제공하여 특정 노드가 격추·고장나도 다른 경로로 통신이 유지된다. 방산 군집에서 생존성이 높아 선호된다.

**팁**: Mesh = 다중 경로 = 내결함성. Star = 단일 허브 = SPOF 취약. Token Ring = 순서 보장.

### Q265. ORCA(Optimal Reciprocal Collision Avoidance) 알고리즘에서 '상호(Reciprocal)'의 의미는?
-    중앙 서버가 모든 드론의 회피 경로를 계산하여 배포한다
- ✅ 각 드론이 충돌 회피 책임을 상호 분담하여 절반씩 회피 기동을 취한다
-    충돌 예상 시 한쪽 드론만 회피 기동하고 다른 드론은 직진한다
-    드론 간 통신 없이 관성만으로 충돌을 회피한다

**해설**: ORCA에서 Reciprocal은 충돌 회피 책임을 두 드론이 절반씩 분담한다는 의미다. 각 드론이 속도 장애물(Velocity Obstacle) 절반을 회피함으로써 전체 충돌이 방지된다.

**팁**: ORCA = 상호 분담 회피. 각 에이전트가 VO(Velocity Obstacle)의 절반만 처리하면 된다.

### Q266. 드론 군집의 분산 경로 계획에서 'Potential Field(포텐셜 필드)' 기법의 기본 원리는?
-    목표 지점은 척력장, 장애물은 인력장을 생성하여 드론을 유도한다
- ✅ 목표 지점은 인력장, 장애물은 척력장을 생성하여 드론을 유도한다
-    모든 장애물을 피해 최단 경로를 그래프 탐색으로 계산한다
-    각 드론이 무작위 방향으로 이동하며 최적 경로를 탐색한다

**해설**: APF(Artificial Potential Field)에서 목표는 인력장(Attractive Field)으로 드론을 끌어당기고, 장애물은 척력장(Repulsive Field)으로 드론을 밀어낸다. 두 힘의 합력 방향으로 드론이 이동한다.

**팁**: APF: 목표=인력(+), 장애물=척력(-). 단점: 지역 최솟값(Local Minima)에 빠질 수 있음.

### Q267. 군집 드론 시뮬레이션에서 GPU 병렬 처리를 활용하는 주된 이유는?
-    GPU는 CPU보다 단일 스레드 연산 속도가 훨씬 빠르기 때문이다
- ✅ 수천 개 드론의 물리 시뮬레이션을 수천 개 코어에서 동시 병렬 처리할 수 있기 때문이다
-    GPU가 통신 프로토콜 처리에 특화되어 있기 때문이다
-    GPU는 메모리 대역폭이 낮아 시뮬레이션 정확도가 높기 때문이다

**해설**: GPU는 수천~수만 개의 SIMT(Single Instruction Multiple Thread) 코어를 병렬 실행할 수 있어, 다수 드론의 물리 역학 계산을 동시에 처리하기에 적합하다. NVIDIA Isaac Sim 등이 이를 활용한다.

**팁**: GPU 병렬 처리: 드론 수 = 스레드 수. 100대 이상 군집 시뮬레이션에는 GPU가 필수적이다.

### Q268. 군집 드론에서 드론별 고유 ID 체계가 필요한 가장 핵심적인 이유는?
-    드론 제조사를 식별하여 보증 서비스를 받기 위해
- ✅ GCS에서 개별 드론 명령·상태 구분 및 MAVLink 시스템 ID 충돌 방지를 위해
-    비행 중 드론 무게 변화를 추적하기 위해

-    중앙 허브 드론에 모든 트래픽을 집중시켜 에너지를 절약한다

**해설**: 토폴로지 제어(LMST, RNG, GG 등 알고리즘)는 그래프 연결성을 보장하는 최소 스패닝 트리 또는 플래너 그래프를 구성하면서 각 드론의 송신 전력을 줄인다. 이를 통해 전체 군집 네트워크 수명이 최대화된다.

**팁**: 토폴로지 제어 목표: 연결성 유지 + 송신 전력 최소화 → 군집 수명 최대화.
