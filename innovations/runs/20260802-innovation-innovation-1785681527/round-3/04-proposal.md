# Innovation Proposal

## 조합 요소
Pixhawk 초기 파라미터 설정 + GeoComm 미션 존 메타데이터

## 발상
Pixhawk 초기 파라미터 설정 이벤트를 "언제, 어느 지리적 미션 구역에서, 어떤 규정 하에" 값을 정했는지를 기록하는 지리서명(geo-signed) 이력으로 만든다. 파라미터 값 자체가 아니라, 그 값이 성립한 시공간·규제적 근거를 GeoComm의 미션 존 메타데이터와 묶어 하나의 감사 가능한 레코드로 남긴다.

## 후보 타입
Patent Candidate — novelty 7, feasibility 7로 모두 높고, "파라미터 값 + GPS 좌표 + PKI 서명 + 미션 존 규제 메타데이터를 하나의 감사 가능 레코드로 결합"하는 구체적 메커니즘이 제시되며 유사 선행사례가 확인되지 않음. 특정 단일 운용 목적(정찰/배송 등)을 갖는 미션형이 아니라 설정 절차 자체를 보호하는 기술 구성요소에 해당함.

## Innovation Score
- Novelty: 7/10
- Feasibility: 7/10
- Value: 7/10 — 여러 규제 구역을 넘나드는 상업용 BVLOS 운영사가 사고 조사·보험 청구 시 "당시 설정이 해당 구역 규정에 부합했음"을 입증해야 하는 상황, 규제기관 감사 대응 담당자, 사고 후 제품책임 방어가 필요한 드론 제조사 — 이들 모두에게 "설정이 확정된 시점의 지리적·규제적 근거"를 사후에 반박 불가능하게 제시할 수 있는 레코드는 구체적이고 반복적으로 발생하는 실무 수요임.
- RiskPenalty: 1/10
- **Total**: 0.3×7 + 0.3×7 + 0.25×7 − 0.15×1 = 2.1 + 2.1 + 1.75 − 0.15 = **5.80**

## 왜 지금까지 없었는가
파라미터 설정은 통상 "기체가 안전하게 나는가"라는 기술적 관점에서만 다뤄지고, GeoComm 같은 지리적 통신/미션 컨텍스트 시스템은 "지금 어디서 무엇을 전달할 것인가"라는 운영 관점에서만 다뤄져 왔다. 설정 행위 자체를 사후 감사 대상으로 보는 관점이 초기 파라미터링 단계까지 내려온 적이 없었던 것으로 보인다. 검색 결과에서도 GeoComm은 일관되게 DFR Routing 등 운용 단계 기능으로만 등장하고, Pixhawk/ArduPilot 관련 자료는 파라미터를 정적 기본값 표로만 다룰 뿐 설정 행위의 출처·컨텍스트 감사는 다루지 않아, 이 결합의 신규성이 뒷받침된다. 다만 "지리서명"이라는 메커니즘 자체(암호서명+지리좌표+규제 메타데이터 결합)는 문서서명·위치증명 등 타 도메인에서는 익숙한 패턴이라 완전한 백지 발명은 아니다.

## 만들 수 있는가
GCS 소프트웨어에서 파라미터 설정 시점의 GPS 좌표 기록, 표준 PKI 서명, 미션 존 메타데이터 결합은 모두 현존 기술이며 새 하드웨어가 필요 없다. Pixhawk/ArduPilot/PX4는 이미 파라미터 로깅·버전관리 인프라(파라미터 파일, dataflash 로그)를 갖추고 있어 여기에 서명·지리컨텍스트 필드를 추가하는 확장은 현실적이다. 다만 "지리좌표 → 규제 근거"를 표준화된 스키마로 자동 매핑해줄 신뢰 가능한 데이터 소스가 실제 존재하는지는 검증되지 않았으며, 이 부분이 구현 병목이 될 수 있다.

## 무엇이 위험한가
안전·이중용도 우려는 낮다(규제 준수·감사를 강화하는 방향). 다만 설정 시점의 지리좌표를 기록·서명해 장기 보관하므로, 해당 레코드가 운용자·기체의 위치 이력을 노출할 수 있어 접근 권한 관리 등 통상적인 데이터 프라이버시 처리가 필요하다.

## 누구에게 가치 있는가
- 여러 규제 구역을 넘나드는 BVLOS 상업 운영사: 사고·이상비행 발생 시 "설정이 당시 구역 규정에 부합했다"는 반박 불가능한 증거 확보
- 보험사·손해사정 담당자: 청구 심사 시 설정 시점의 규제 근거를 검증 가능한 형태로 확인
- 드론 제조사 법무·품질 부서: 제품책임 소송 시 "인도 시점 설정이 규정을 따랐음"을 입증하는 방어 자료
- 규제기관 감사팀: 사업자별 설정 이력을 지리·시점별로 일괄 조회·검증

## 다음 단계 — 완전히 새로운 질문
기체가 임무 도중 서로 다른 규제·통신 조건을 가진 지리적 구역 경계를 넘나들 때, 이미 확정된 초기 파라미터(또는 지리서명 이력)를 그대로 유지해야 하는가, 아니면 구역 전환 시점마다 재설정이 필요한가 — 그리고 그런 재설정이 일어난다면 "최초 설정"이라는 개념 자체가 감사 관점에서 여전히 유효한 단일 사건으로 성립할 수 있는가?
