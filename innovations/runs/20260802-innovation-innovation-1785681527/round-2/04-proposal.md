# Innovation Proposal

## 조합 요소
MAVLink 2 메시지 인증·확장 슬롯 + 세컨드 브레인 evidence_tier(인식론적 신뢰도 등급) 개념

## 발상
MAVLink 2 텔레메트리 패킷에 "이 필드값의 출처 신뢰도 등급"을 실시간으로 임베드하는 프로토콜 확장. 온보드 센서 직접 측정값, 다른 드론이 중계한 값, 지상국이 추정·보간한 값을 스웜 내에서 구분해, 수신 측 자율 판단 로직이 "이 데이터를 얼마나 믿고 반응할지"를 메시지 자체에서 읽을 수 있게 한다.

## 후보 타입
Patent Candidate — 3단계 출처 구분(온보드 직접측정/드론 중계/지상국 추정)을 MAVLink 2의 기존 서명·확장 메시지 슬롯(ID 180-229)에 임베드하는 구체적 메커니즘이 있으며, 단일 벤더 시스템 단위 청구항 작성이 가능한 수준.

## Innovation Score
- Novelty: 7/10
- Feasibility: 6/10
- Value: 6/10 — PX4/ArduPilot 기반 다중 드론 스웜 운용자(농업 방제, 수색구조, 배송 플릿)가 다중 홉 중계 환경에서 "이 값이 실측인지 추정인지" 모호성을 안고 있으며, 신뢰도 미구분 시 자율 회피 로직이 오래된 중계값을 실측처럼 취급해 오판할 위험이 실재한다. 다만 이 가치는 다중 홉 중계 아키텍처를 실제 운용하는 조직에 한정되고, 벤더 간 taxonomy 표준화 전까지는 개별 시스템에 종속된 구현에 머물러 즉시 광범위한 수요로 확산되지는 않는다.
- RiskPenalty: 2/10
- **Total**: 0.3×7 + 0.3×6 + 0.25×6 − 0.15×2 = 2.1 + 1.8 + 1.5 − 0.3 = **5.1**

## 왜 지금까지 없었는가
통신 프로토콜 보안 엔지니어링(암호학적 무결성·인증)과 evidence_tier 같은 인식론적 신뢰 등급 체계(연구 방법론)는 서로 다른 커뮤니티에서 독립적으로 발전해왔다. "메시지가 위조되지 않았다"와 "메시지 내용을 얼마나 믿을 만한가"가 서로 다른 축이라는 인식이 실시간 제어 프로토콜 설계에 잘 반영되지 않았다. 로컬 코퍼스 내 MAVSec 등 기존 문헌도 인증·무결성·기밀성만 다룰 뿐, 필드값 출처에 따른 신뢰도 구분은 등장하지 않는다(단, 이는 로컬 자료 범위에 한정된 판단이며 외부 학계의 provenance-aware sensor fusion 연구와의 중복 여부는 확인되지 않았다).

## 만들 수 있는가
MAVLink 2는 서명 필드, component targeting, 사용자 정의 메시지(ID 180-229) 확장 슬롯을 이미 제공하므로, 단일 벤더 폐쇄형 스웜 시스템에서는 "신뢰도 등급 필드" 추가가 기존 확장 메커니즘 안에서 즉시 시도 가능하다. 다만 스웜 내 다중 홉 중계 시 출처 메타데이터를 보존하는 라우팅 계층이 표준에 없고, 신뢰도 등급 taxonomy를 PX4·ArduPilot 양쪽 생태계가 합의해야 상호운용 표준으로서 의미를 가지는데 이는 기술이 아니라 거버넌스 문제라 시간이 걸린다.

## 무엇이 위험한가
정보 표시 확장으로 제어 로직이나 표적화 기능을 포함하지 않아 위험도는 낮다. 다만 신뢰도 인식 통신 프로토콜은 민간(배송·점검 스웜)뿐 아니라 군용 스웜 통신에도 적용 가능한 이중용도 인프라 기술이므로, 표준화가 진행될 경우 채택 주체를 구분해 검토할 필요가 있다.

## 누구에게 가치 있는가
다중 홉 중계 방식으로 운용되는 드론 스웜 시스템의 운용자·개발자 — 농업 방제 스웜, 수색구조 스웜, 배송 플릿 등 자율 판단 로직이 실측값과 중계·추정값을 구분해야 오작동을 피할 수 있는 시나리오. PX4/ArduPilot 생태계에서 신뢰도 taxonomy 표준화를 주도할 프로토콜 워킹그룹에도 직접적 가치가 있다.

## 다음 단계 — 완전히 새로운 질문
이 evidence_tier 메타데이터가 사고 조사·기체 인증 절차에서 법적 증거능력을 가지려면 어떤 요건을 충족해야 하는가 — 즉 "이 데이터는 온보드 직접측정이었다"는 프로토콜 수준의 자기선언이, 사후 조사기관(항공안전당국 등)이 신뢰할 수 있는 감사 가능한(auditable) 기록으로 인정받으려면 무엇이 추가로 필요한가?
