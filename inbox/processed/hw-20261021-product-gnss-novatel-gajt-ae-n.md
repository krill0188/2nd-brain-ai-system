# NovAtel (Hexagon) GAJT-AE-N anti-jam antenna electronics

출처 유형: 제조사 공식 제품 페이지. novatel.com 직접 접속은 403이라 web.archive.org 보관본으로 열람. 전자부(antenna electronics)만 해당 — CRPA 안테나는 별도.

## 핵심 사양 (출처 페이지에 적힌 값만)

| 항목 | 값 |
|---|---|
| 구성 | RF front end + null forming electronics. 4-element CRPA 중 선택(페이지 문구: 'variety of 4-element CRPAs') |
| 권장 안테나 | Antcom 표준 또는 맞춤 형상 안테나(권장 문구) |
| 간섭 완화 방식 | proprietary digital beamforming 으로 재머 방향에 동적 null 형성, narrowband·broadband 모두 대응, 다중 재머 상황 대응 |
| 보호 대역 변형 | L1 및 L2, 또는 L1 만; wide/narrow band 버전. wide 버전은 M-code 호환 대비(문구) |
| 출력 | 표준 RF feed — 레거시 GPS 수신기에 입력 가능 |
| 전원 | LEMO 커넥터로 DC 공급 |
| 설치 | 차량 내부에 전자부를 설치하고 안테나만 외부에 두는 구성 권장(소형 무인 항공·지상 플랫폼) |
| 크기·무게·소비전력·억제 dB | 미확인(제품 시트 PDF 는 열지 않음) |

## 용도
페이지 문구: 크기·무게 제약이 있는 소형 공중·지상 무인 플랫폼용(small airborne and ground unmanned platforms).

## 호환·인터페이스
기존 GAJT-310/710ML/AE3 파일은 별도(기존 수집). 이 제품은 전자부만 분리된 형태.
