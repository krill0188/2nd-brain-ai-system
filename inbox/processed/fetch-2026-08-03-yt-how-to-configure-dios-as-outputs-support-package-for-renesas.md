## 설명 요약

Learn how to configure the DIO pins of a Renesas® RH850/U2A Starter Kit as digital outputs using the MCAL DIO Channel Write block from Embedded Coder Support Package for Renesas RH850 Microcontrollers in Simulink®. In this example, you will write data to a DIO pin and blink the onboard LED on the RH850/U2A Starter Kit.
