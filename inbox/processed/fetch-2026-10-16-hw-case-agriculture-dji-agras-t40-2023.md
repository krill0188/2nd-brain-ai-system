# DJI Agras T40 농업 방제 드론 운용

## 개요

DJI Agras T40은 농약·비료 살포 전용 대형 멀티로터 드론이다. 브라질 항공청(ANAC) 인가 파일(2024년 3월)과 dronespec.dronedesk.io 사양 시트를 주요 출처로 활용했다. 한국 포함 동아시아(중국·일본·한국)에서 대규모 상업 운용 중.

## HW 구성 (표)

| 항목 | 수치 | 출처 신뢰도 |
|------|------|------------|
| 로터 구성 | 4축 동축(coaxial) 8로터 | 높음(ANAC 파일) |
| 모터 수 / 정격 출력 | 8개, 각 4,000 W | 높음(dronespec) |
| 모터 KV | 48 KV | 중간(dronespec, 1차 출처 미확인) |
| 기체 중량 (배터리 제외) | 약 38 kg | 높음(ANAC) |
| 기체 중량 (배터리 포함) | 약 50 kg | 높음 |
| 최대 이륙 중량 (살포) | 90 kg | 높음(ANAC) |
| 최대 이륙 중량 (살포, spreading) | 101 kg | 높음(ANAC) |
| 살포 탱크 용량 | 40 L (페이로드 40 kg) | 높음(ANAC) |
| 살포 유효 폭 | 최대 약 11 m | 중간(판매 자료) |
| 살포 커버리지 | 최대 약 52 에이커/시간 (이상 조건) | 중간 |
| 비행 시간 (90 kg MTOW, 30Ah 배터리) | 약 7분 | 중간(ANAC 파일) |
| 배터리 | 30 Ah (모델 미확인) | 중간 |

## 성과·한계

- 고부하 코액셜 구성으로 단위 면적 당 운용 효율 극대화.
- 비행 시간 7분은 재충전 또는 배터리 교환 기반 운용 필요 → 지상 스테이션 필수.
- **한계:** 모터 모델명, ESC 사양은 공개 미확인. 실제 한국 운용 실적 데이터 미확인.
- 동일 계열 T50(페이로드 50 kg)도 존재하나 상세 모터 사양 미확인.

## 출처의 신뢰도

- ANAC(브라질 항공청) 인가 파일 (Tier 0): **높음** — 공식 규제 기관 문서
- dronespec.dronedesk.io (Tier 2): **중간** — DJI 공식 자료 기반이나 제3자 정리
- 확인 날짜: 2026-10-16
