# Oak Ridge Fire 산불 감시 - Parrot Anafi·Alta X (미국 콜로라도)

## 개요

2024년 6월 22일 콜로라도 Beulah 인근에서 발생한 Oak Ridge Fire에서 접근이 어려워 소방관 위험이 큰 상황을 드론으로 보완한 사례. USDA Forest Service 기사(2024년 11월 5일)에 따르면 드론 2대를 투입했다. 소형 Anafi(Parrot)는 화재 경계 실시간 영상과 적외선 열점 탐지를 맡았고, 대형 Type 3 Alta X는 함께 운용됐다. 7월 12일 InciWeb 업데이트는 적외선 드론을 열 지점 탐지·매핑에 계속 사용한다고 기록했다.

## HW 구성 (표)

| 항목 | 수치 | 출처 신뢰도 |
|------|------|------------|
| 소형 기체 | Parrot Anafi (적외선 카메라 탑재) | 중간(USFS 기사 발췌) |
| 대형 기체 | Alta X (Type 3 UAS 분류) | 중간 |
| 탑재 센서 | 적외선(IR) 카메라, 실시간 영상 | 중간 |

| 비행 시간·배터리·중량 | 미확인 | — |

## 성과·한계

- 기사 주장: 적외선 드론으로 화재 경계 내외 열점을 찾아 지상 진화팀에 전달.
- 화재 규모: 기사·InciWeb 기준 1,310 acre, 7월 12일 기준 85~89% 봉쇄(보도마다 수치 상이, Denver Gazette 1,193 acre로 표기).
- **한계:** 탐지 개선률·대응 시간 등 정량 평가 없음. 사후 보고서 미확인. 제조사 자료 혼재.

## 출처의 신뢰도

- USDA Forest Service 기사: **중간** — 공공기관 발행이나 본 수집 환경에서 원문 직접 접근 불가(403), 검색 발췌로만 확인.
- InciWeb 업데이트: 원문 접근 불가(403), 검색 결과 요약으로만 확인 → 교차 검증 필요.
