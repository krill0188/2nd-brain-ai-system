# Furuno GN-87 Multi-GNSS Receiver Module

출처 유형: 제조사 공식 제품 페이지(스펙 탭 텍스트).

## 핵심 사양 (출처 페이지에 적힌 값만)

| 항목 | 값 |
|---|---|
| 채널 수 | 32 channels (GPS, GLONASS, Galileo, QZSS, SBAS) |
| 지원 신호 | GPS L1 C/A, GLONASS L1OF, QZSS L1 C/A, SBAS L1 C/A, Galileo E1B/E1C (QZSS L1S 대응 준비) |
| 위치 정확도(수평) | GPS 2.5 m CEP; GPS+SBAS 2.0 m CEP; GPS+SBAS+GLONASS 2.0 m CEP (1 Hz) |
| 갱신율 | 1 / 2 / 5 / 10 Hz |
| TTFF(Typical) | Hot <1 s, Warm 30 s, Cold 33 s (@-130 dBm) |
| 감도(GPS) | Tracking -161, Cold/Warm -147, Reacq -161 dBm |
| 재밍 | 'Active Anti-Jamming' 문구(수치 없음) |
| 크기 | 24-pin LCC, 12.2 x 16.0 x 2.8 mm |
| 전원 | 3.3 VDC; Acquisition 72 mA |
| 동작 온도 | -40~+85 C |
| 프로토콜 | eSIP(NMEA 0183 Ver 4.10), FURUNO Binary |

## 용도
페이지 문구: 자동차용 표준 크기 L1 멀티 GNSS 모듈.

## 호환·인터페이스
활성/수동 안테나 선택 가능(페이지 문구).

## 비고(미확인)
단일 주파수(L1)이며 RTK 미지원 — 드론 정밀 측위 용도로는 사양 제한적. 무게 미확인.
