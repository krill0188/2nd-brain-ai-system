## 설명 요약

Learn how to configure the DIO pins of a Renesas® RH850/U2A Starter Kit as digital inputs using the MCAL Digital Channel Read block from Embedded Coder Support Package for Renesas RH850 Microcontrollers in Simulink®. In this example, you will configure a DIO pin as a digital input and read the status of a switch on the Renesas RH850/U2A Starter Kit.
