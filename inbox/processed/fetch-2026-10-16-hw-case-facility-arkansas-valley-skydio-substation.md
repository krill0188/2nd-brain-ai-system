# Arkansas Valley Electric Cooperative 변전소 Skydio 3D 스캔 점검

## 개요

미국 전력 협동조합 AVECC가 관할 변전소 36곳을 Skydio 드론과 3D 스캔 기술로 점검하는 사례. 고객 사례 페이지(제조사 게재)에 따르면 기존 방식은 6~7명 팀이 1일 촬영 후 며칠간 사무실 분석이 필요했다. 도입 후 2~3인 팀 운용으로 바뀌었다.

## HW 구성 (표)

| 항목 | 수치 | 출처 신뢰도 |
|------|------|------------|
| 기체 | Skydio 드론 (사진 캡션상 X10, 본문 미확인) | 낮음 |
| 소프트웨어 | 3D 스캔 기술 | 높음(페이지 명시) |
| 점검 대상 | 변전소 36곳 | 높음 |
| 운용 방식 | 수동 이륙 후 대상 선택 자동 스캔, 배터리 1~2회 교체 | 중간(담당자 인터뷰) |
| 도크 | 언급 없음 | — |
| 탑재 센서·배터리 사양 | 미확인 | — |

## 성과·한계

- 제조사 보도: 점검 시간 50% 절감, "60+ 시간" 절감. 독립 검증 없음.
- 기존 대비 인력 구성 변화(6~7명 → 2~3명)는 고객 페이지 기술.
- **한계:** 기체 모델이 본문에 명시되지 않음. 발행일 미확인(페이지 푸터는 저작권 연도). 센서·배터리 사양 미확인.

## 출처의 신뢰도

- Skydio 고객 사례 페이지(제조사 게재): **중간** — 정량 수치는 제조사 주장.
- 확인 날짜: 2026-10-16
