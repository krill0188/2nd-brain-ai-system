# TUALCOM TUALAJ 4200-MINI CRPA GNSS Anti-Jam System

출처 유형: 제조사 데이터시트 PDF(2쪽, © 2026 TUALCOM) — 유통/카탈로그 사이트 unmannedsystemstechnology.com 게재 사본. 요청 목록(Safran·Orolia·Raytheon·Hexagon) 외 제조사지만 드론 탑재 가능한 소형 CRPA 사양이 열려 추가.

## 핵심 사양 (출처 페이지에 적힌 값만)

| 항목 | 값 |
|---|---|
| 안테나 | 4-element CRPA |
| 동시 독립 null 수 | 3 (재머 3방향, 2개 주파수 대역) |
| 보호 대역 옵션 | Option 1: GPS L1/L2, Galileo E1, BeiDou B1, SBAS; Option 2: GPS L1/L5, Galileo E1/E5a, BeiDou, SBAS; Option 3: GPS L1, GLONASS G1, Galileo E1, BeiDou B1, SBAS |
| 추가 기법 | adaptive notch filtering, pulse blanking 병행 |
| 크기 | DACU 7.9 x 5.65 x 1.9 cm; 안테나 옵션1 10.5 x 10.5 x 2.3 cm, 옵션2 7 x 7 x 1.1 cm |
| 무게 | DACU 190 g; 안테나 옵션1 430 g, 옵션2 100 g |
| 소비전력 | 최대 12 W |
| 전압 | 12-28 Vdc |
| 동작 온도 | -40 ~ +85 C |
| 커넥터 | 5x MCX female, Micro-D 25-pin socket |
| 인터페이스 | Serial RS-232, RS-485 |
| 내장 수신기(옵션) | GPS L1, GLONASS L1, Galileo E1, BeiDou B1, SBAS, QZSS L1, RTCM 지원 |
| 규격 | MIL-STD-810G, MIL-STD-461F |
| 억제량(dB) | 데이터시트 표에 없음 — 미확인(별도 검색 요약에서 '>40 dB'로 인용된 값이 있으나 이 PDF에서는 확인 못함) |

## 용도
문서 문구: 고정익·회전익 항공기, 무인 자율 시스템, 지상차량, 해상 플랫폼 등.

## 호환·인터페이스
외부 GNSS 수신기(M-code 포함)와 연동, 임베디드 수신기 옵션.

## 비고(미확인)
수출 규제·가격·실제 드론 시험 결과 미확인.
