## 설명 요약

Integrated sensing and communication (ISAC) is a key 6G concept that uses a single waveform for both data transmission and radar sensing. Use MATLAB®, Simulink®, and Wireless Testbench™ to implement a target emulator on an NI™ USRP™ FPGA. By applying configurable delay, Doppler shift, and gain, the emulator generates realistic radar reflections that represent moving targets in a repeatable hardware-in-the-loop environment.
