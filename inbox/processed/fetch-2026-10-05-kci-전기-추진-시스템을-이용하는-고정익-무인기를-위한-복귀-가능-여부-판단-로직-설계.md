## Abstract

Ensuring mission safety requires real-time assessment of UAV status to determine the feasibility of a safe return-to-base(RTB) under unexpected interruptions. This paper presents the real-time return feasibility decision logic design for fixed-wing UAV with electric propulsion to return the UAV safely during the mission. For logic design, the return feasibility was decided from the predicted remaining voltage based on the predicted energy consumption by using flight vertical and horizontal ranges to designed return point. If the predicted remaining voltage at the predefined return point falls below a required threshold, a remaining flight range is computed, enabling dynamic adjustment of the return point.
