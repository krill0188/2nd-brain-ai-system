# Chelton Anti-Jam GPS DACU8b (8-Channel Nulling & Beamforming)

출처 유형: 제조사 공식 제품 페이지(사양 탭). CRPA 안테나 어레이와 GPS 수신기 사이에 들어가는 8채널 처리기(DACU).

## 핵심 사양 (출처 페이지에 적힌 값만)

| 항목 | 값 |
|---|---|
| 채널 수 | 8 channel (software defined GPS anti-jam processor) |
| 방식 | nulling and beamforming — 지향성 null 과 조향 빔 생성(broadband interference 대응) |
| 재머 방향탐지 | 다중 공간분리 재머 방향을 5도보다 좋은 정확도로 추정(플랫폼 캘리브레이션 시) |
| 입력 전압 | 28 V dc nominal (+16 ~ +32 V) |
| 소비전력 | <50 W (continuous) |
| RF | Max RF input < -10 dBm, VSWR better than 2:1, Noise figure <5 dB, Gain +15 ~ +35 dB |
| 크기 | Length 256 mm x Width 86 mm x Height 128 mm |
| 무게 | Max 2.25 kg |
| 동작 온도 | -40 ~ +71 C (operational), 고도 55,000 ft |
| 환경 규격 | MIL-STD-810G CHG-1 Meth 503.6 (온도충격), Meth 507.5 (습도) |
| 억제량(dB) | 미확인 |
| 적용 | 페이지 문구: KAI KF-21 에 적용(Honeywell EGI 사용) |

## 용도
페이지 문구: 소형 항공·무인 설치 같은 크기·무게 제약 플랫폼용(small airborne and unmanned installations)이라 설명하나, 위 표 기준 2.25 kg·<50 W 로 소형 멀티콥터에는 큼.

## 호환·인터페이스
CRPA 안테나 옵션·케이블 길이 선택, EGI 인터페이스 맞춤 가능(문구).
