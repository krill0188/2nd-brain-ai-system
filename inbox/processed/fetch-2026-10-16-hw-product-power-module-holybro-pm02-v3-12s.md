# PM02 V3 Power Module (12S) — Holybro

## 핵심 사양 (공식 페이지 게재값)

| 항목 | 값 |
|---|---|
| 입력 전압 | 2S–12S |
| PCB 연속 전류 정격 | 60A |
| PCB 버스트 전류 정격 | 100A (<60초) |
| 최대 전류 센싱 | 120A |
| 출력 | DC 5.2V & 3A max |
| 전압 분배비 | 18.182 |
| Amperes per Volt | 36.364 |
| 무게 | 20g |
| 크기 | 미확인 |
| 데이터 출력 | 아날로그 (6핀 JST-GH) |

## 용도

- 2S–12S 배터리 기체의 전원 분배 및 전압·전류 측정 (아날로그 방식 FC용)

## 호환·인터페이스

- 아날로그 데이터 출력, 6-pin JST-GH 케이블
- Pixhawk 5X·6X 호환 불가 → 디지털 PM(PM02D) 필요
- 기본 포함: XT60 커넥터 보드 (pre-soldered), 220uF 63V 커패시터

## 비고

- 공식 페이지 주의: XT60 플러그·12AWG 와이어 정격은 연속 30A / 버스트 60A(<60초). 그 이상 전류는 커넥터·배선 변경 필요.
- 수집 방식: 공식 페이지 확인(2026-10-16). WebFetch 요약 기준으로 값 옮김, 원문 수치 재대조 권장.
- 출처 신뢰도: 높음 (제조사 공식 페이지)
