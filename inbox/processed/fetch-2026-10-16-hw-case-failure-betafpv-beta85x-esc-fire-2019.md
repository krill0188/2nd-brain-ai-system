# BetaFPV Beta85X ESC 화재 사고 - 불량 납땜 및 과전류 원인

## 개요

BetaFPV가 제조한 Beta85X 소형 FPV 드론에서 ESC 화재 사고가 발생. 2019년 2월 22일 제조사가 공식 발표. **초도 생산분 2,000대 중 약 100건(~5%)의 화재 사고** 분석. 독립 기관 조사가 아닌 제조사 자체 발표이므로 신뢰도 한계 있음.

## HW 구성 (표)

| 항목 | 수치 | 비고 |
|------|------|------|
| 기체 | BetaFPV Beta85X | 소형 FPV 드론 |
| ESC 종류 | BLHeli_32 통합 ESC | |
| 모터 | 1105 | |
| 배터리 | 4S LiPo | 사고 조건 |
| 초도 생산 수량 | 2,000대 | |
| 화재 건수 (분석 시점) | 약 100건 (~5%) | 제조사 집계 |
| 불량률 (ESC 보드) | 약 1% | 제조사 추정 |

## 고장 메커니즘

1. **불량 납땜:** BLHeli_32 ESC 보드의 일부 부품이 불량 납땜 → 고전류 하에서 접촉 불량 발생.
2. **과전류 조건:** 4S 배터리 + 풀 스로틀 지속 시 ESC·모터가 연속 전류를 감당하지 못함.
3. **실험 결과:** 벤치 테스트에서 4S 풀 스로틀 15~20초 후 ESC·모터 화재 발생 확인.
4. **탐지 실패 원인:** 프로토타입 50대로 충분한 내구 시험을 수행하지 않았고, BLHeli_32 대량 생산 품질 관리 경험 부족.

## 성과·한계

- **교훈 1:** 새 ESC 도입 시 **실제 비행 부하(풀 스로틀 지속)** 조건의 열 시험 필수.
- **교훈 2:** 납땜 품질 관리 → AOI(자동 광학 검사) 등 100% 검사 체계 필요.
- **교훈 3:** 배터리 셀 수(전압)와 ESC 정격 전류의 안전 여유 확인 → 4S+1105 조합은 한계 초과.
- **제조사 조치:** 4S 배터리 사용 중단 권고, 보증 교체, 생산·시험 기준 개선 약속.
- **한계:** 독립 기관 조사 없음. 제조사 자체 발표. 근본 원인(설계 vs 생산) 명확 구분 없음.

## 출처의 신뢰도

- BetaFPV 공식 블로그 (제조사 자체): **중간** — 독립 조사 없음, 수치 교차 확인 불가. 참조 가능하나 HW 설계 결정의 유일 근거로 사용 부적합.
- 확인 날짜: 2026-10-16
