# What Is Deep Learning Toolbox?

## 설명 요약

Deep Learning Toolbox provides functions, apps, and Simulink® blocks for designing, training, and simulating deep neural networks. You can visualize and interpret predictions, verify network properties, and compress networks with pruning, projection, or quantization. You can also generate C/C++, CUDA®, and HDL code for trained networks (with MATLAB Coder™, GPU Coder™, or Deep Learning HDL Toolbox™). The toolbox provides interfaces to other AI frameworks, enabling inference in MATLAB and Simulink

## 자막 (자동 추출, 최대 8000자)

Deep Learning Toolbox provides functions, apps, and Simulink blocks that enable engineers to train and use deep learning models in applications like visual inspection, wireless communications, reduced order modeling, and computer vision. The Deep Network Designer lets you interactively import models from other deep learning frameworks, load built-in models, and edit or build your own models. You can analyze and modify models for transfer learning and export them to Simulink. The Time Series Modeler app lets you interactively build, train, evaluate, and compare models for sequence and time series data. With Deep Learning Toolbox, you can test and deploy deep neural networks. Deep learning with Simulink allows you to simulate the performance of neural networks within larger systems. For deployment to CPUs, GPUs, FPGAs, and systems-on-chip, you can automatically generate C, C++, CUDA, and HDL code for your trained networks. The toolbox integrates Python-based deep learning frameworks. Import PyTorch, ONNX, and TensorFlow models with one line of code. Export networks to TensorFlow and ONNX just as easily. Co-execute any Python-based model in MATLAB and Simulink. In addition to simulation, you can use robustness verification and explainability techniques. This ensures your deep learning models work as intended before deploying to target. You can compress neural networks with pruning, data-driven projection, or quantization. These methods reduce memory use and increase inference performance for deployment to resource-constrained devices. The toolbox provides hundreds of reference examples showing the applications of deep learning for engineered systems from image processing and computer vision, signal processing, audio and wireless to reduced order modeling and more.
