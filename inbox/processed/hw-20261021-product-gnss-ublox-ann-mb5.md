# u-blox ANN-MB5

출처 유형: u-blox 데이터시트의 SparkFun CDN 복제본(u-blox 직접 URL은 이번에 확인 못 함).

## 핵심 사양 (출처 페이지에 적힌 값만)

| 항목 | 값 |
|---|---|
| 지원 대역 | L1 (1559~1608 MHz), L5/E5a/B2a/NavIC (1164~1186 MHz) |
| 소자 | single-feed stacked patch, RHCP |
| 안테나 이득(zenith) | L1 typ. 4.5 dBic / L5 typ. 4.0 dBic |
| LNA 이득 | L1 typ. 15 ± 3.0 dB / L5 typ. 16 ± 3.0 dB |
| LNA 잡음지수 | typ. 2.0 dB (양 대역) |
| 총 이득(3 m RG-174 포함) | L1 typ. 11.4 dB / L5 typ. 12.7 dB |
| 입력 전압 | 3.0 ~ 5.0 V |
| 소비 전류 | typ. 17 mA |
| 크기 | 49.14 x 46.14 x 15.94 mm |
| 무게 | 104 g (typ., 케이블 포함) |
| 커넥터·케이블 | SMA(plug), RG174 3.0 m |
| 마운트 | 자석 베이스 |
| 방수·온도 | IPX7, 동작 -40 ~ +85 °C |
| 기타 | 과전압·역전압 보호 없음(전원 절대최대 6.0 V) |

## 용도
u-blox F10 등 L1/L5 standard precision(미터급) 플랫폼용. 드론 표기 없음.

## 호환·인터페이스
5 V 이하 단일 공급, SMA.

## 비고(미확인)
드론 전용 설계 여부 미확인.
