# u-blox MAX-M10S (MAX-M10 series 페이지)

## 핵심 사양 (출처 페이지에 적힌 값만)

| 항목 | 값 |
|---|---|
| 지원 위성군 | BeiDou, Galileo, GLONASS, GPS / QZSS (변형에 따라 SBAS 포함) |
| 주파수 대역 | L1 대역 위주(페이지 대역 항목 없음, 미확인) |
| 동시 수신 위성군 수 | 'concurrent reception of all major GNSS' 기재, 개수 미확인 |
| 채널 수 | 미확인 |
| 정밀도 | 미확인 |
| RTK/PPK/PPP | 미표기 |
| 갱신율 | 미확인 |
| TTFF | 미확인 |
| 인터페이스 | UART, I2C |
| 입력 전압·소비전력 | 'Less than 25 mW power consumption'; 공급전압 1.76 V ~ 3.6 V (5.5 V 표기 변형 있음) |
| 크기·무게 | 9.7 x 10.1 x 2.5 mm |
| 내장 IMU/컴퍼스/듀얼안테나 방위 | 미확인 |
| 재밍/스푸핑 완화 | 'Advanced spoofing and jamming detection' 기재 |
| 동작 온도 | -40 °C ~ 85 °C |
| PX4/ArduPilot 지원 문구 | 미확인 |

## 용도
u-blox M10 표준정밀 초저전력 GNSS. 페이지가 MAX-M10 시리즈 통합 표라 변형별 열(수정·TCXO 등) 구분이 모호함.

## 호환·인터페이스
위 표의 인터페이스·펌웨어 행 참조. 페이지에 없는 항목은 "미확인"으로 표기.

## 비고(미확인)
시리즈 표 열 구분이 불명확하여 낮은 신뢰도. 표 15개 항목 중 '미확인' 시작 항목 6개.
