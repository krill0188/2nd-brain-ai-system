# Tallysman TW3972 Triple-Band GNSS Antenna + L-band

출처 유형: 제조사 공식 데이터시트 PDF(Revision 1.6, 직접 내려받아 텍스트 추출). 제품 웹페이지(tallysman.com/product/tw3972...)는 JS 렌더링으로 사양이 나오지 않아 PDF로 대체.

## 핵심 사양 (출처 페이지에 적힌 값만)

| 항목 | 값 |
|---|---|
| 지원 대역 | L1/L2/L5, G1/G2/G3, E1/E5a+b, B1/B2/B2a, NavIC L5 + L-band (1164~1254 MHz, 1525~1606 MHz) |
| 안테나 소자 | Dual-feed stacked RHCP ceramic patch |
| 안테나 이득(zenith, dBic typ.) | L1 4 / L2 4 / L5 -1.5 / G1·G2·G3 2.5 / E1 4 / E5a -1.5 / E5b 2.5 / B1 4 / B2 2.5 / B2a -1.5 / L-band 3.5 |
| 축비 | L1 < 1 dB, L5 < 1.5 dB 등(대역별 표기) |
| LNA 이득 | 37 dB typ., 35 dB min. |
| 잡음지수 | 2.5 dB typ. (25 °C) |
| 입력 전압 | 2.5 ~ 16 VDC (nominal, 리플 50 mV p-p 이하) |
| 소비 전류 | 24 mA typ. |
| 크기 | 66 mm x 21 mm (100 mm 접지판 권장) |
| 무게 | 185 g |
| 커넥터 | 주문 코드로 선택(xx = connector type); 구체 종류는 이 PDF에서 미확인 |
| 보호등급 | IP69K (housing) |
| 동작 온도 | -40 °C ~ +85 °C |
| 기타 | ESD 15 kV, VSWR < 1.5:1 typ., LTE 등 셀룰러 대역 사전필터 |

## 용도
정밀 3주파 RTK(측량, 농업, 자율주행). 드론 전용으로 명시되지는 않음. OEM 형태는 TW3967(28 dB)/TW3972E(35 dB)로 안내됨.

## 호환·인터페이스
출력 증폭형 능동 안테나; 마운트는 L 브래킷·파이프 마운트 별매(부품번호 23-0040-0, 23-0065-0).

## 비고(미확인)
커넥터 종류, 위상중심 오프셋 수치는 미확인. 드론 장착 적합성(무게 185 g)은 판단하지 않음.
