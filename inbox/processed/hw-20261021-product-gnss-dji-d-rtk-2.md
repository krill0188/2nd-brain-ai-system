# DJI D-RTK 2 High Precision GNSS Mobile Station

## 핵심 사양 (출처 페이지에 적힌 값만)

| 항목 | 값 |
|---|---|
| 지원 위성군 | GPS, BeiDou, GLONASS, Galileo (11개 신호) |
| 주파수 대역 | GPS L1 C/A, L2, L5; BeiDou B1, B2, B3; GLONASS F1, F2; Galileo E1, E5A, E5B |
| 동시 수신 위성군 수 | 4개 시스템 동시(페이지 FAQ) |
| 채널 수 | 미확인 |
| 정밀도 | 단독 수평 1.5 m / 수직 3.0 m (RMS); RTK 수평 1 cm + 1 ppm / 수직 2 cm + 1 ppm (RMS) |
| RTK/PPK/PPP | RTK 지원(RTCM 2.X/3.X 차분 데이터); PPK/PPP 미확인 |
| 갱신율 | 1 Hz, 2 Hz, 5 Hz, 10 Hz, 20 Hz |
| TTFF | Cold start < 45 s; Hot start < 10 s; 재획득 < 1 s |
| 인터페이스 | 데이터링크: OcuSync, Wi-Fi, LAN, 4G; 메모리 16 GB |
| 입력 전압·소비전력 | 전력 12 W; 입력 16.5 ~ 58.8 VDC; 내장 리튬이온 4920 mAh (37.3 Wh) |
| 크기·무게 | 168 x 168 x 1800 mm (확장 로드 장착), IP65, 무게 미확인 |
| 내장 IMU/컴퍼스/듀얼안테나 방위 | 내장 고정밀 6축 가속도계(움직임 모니터링·경사 측정); 전자 수평기 |
| 재밍/스푸핑 완화 | 미확인 |
| 동작 온도 | -20° ~ 55° C |
| PX4/ArduPilot 지원 문구 | Phantom 4 RTK, MG-1P RTK와 호환 (페이지 FAQ), M210 RTK/D-RTK와는 비호환; PX4/ArduPilot 미확인 |

## 용도
DJI 기체용 이동형 RTK 기지국(삼각대 장착). 페이지 한국어 버전 기준.

## 호환·인터페이스
위 표의 인터페이스·펌웨어 행 참조. 페이지에 없는 항목은 "미확인"으로 표기.

## 비고(미확인)
드론 FC 장착형이 아니라 지상국형. 표 15개 항목 중 '미확인' 시작 항목 2개.
