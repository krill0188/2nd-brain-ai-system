# CUAV C-RTK 9Ps

## 핵심 사양 (출처 페이지에 적힌 값만)

| 항목 | 값 |
|---|---|
| 지원 위성군 | 북두(BeiDou), 갈릴레오(Galileo), 글로나스(GLONASS), GPS (페이지 중국어 원문) |
| 주파수 대역 | GPS L1C/A, L2C; GLONASS L1OF, L2OF; Galileo E1 B/C, E5b; BeiDou B1I, B2I; QZSS L1C/A, L2C |
| 동시 수신 위성군 수 | 4 |
| 채널 수 | 184 채널 ZED-F9P |
| 정밀도 | RTK 0.01 m + 1 ppm CEP; 단독 1.5 m CEP; SBAS 1.0 m CEP |
| RTK/PPK/PPP | RTK 지원; PPK 불지원 (페이지 '不支持') |
| 갱신율 | RTK 20 Hz; RAW 25 Hz; PVT 25 Hz (최대, 구성에 따라 제한) |
| TTFF | Cold start < 24 s; Hot start < 1 s; RTK 수렴 < 60 s |
| 인터페이스 | UART x 2, USB x 1, 안테나 MMCX x 1 |
| 입력 전압·소비전력 | 4.5 V ~ 6 V (소비전력 미확인) |
| 크기·무게 | 47 x 32 x 12.2 mm, 30 g (안테나 제외) |
| 내장 IMU/컴퍼스/듀얼안테나 방위 | IST8310 컴퍼스; 듀얼 모듈 사용 시 듀얼안테나 방위(참고값 0.4°) |
| 재밍/스푸핑 완화 | Active CW detection and removal(능동 CW 검출·제거) |
| 동작 온도 | -40 ℃ ~ 85 ℃ |
| PX4/ArduPilot 지원 문구 | 미확인 |

## 용도
ZED-F9P 기반 RTK 기지국/이동국 겸용 모듈.

## 호환·인터페이스
위 표의 인터페이스·펌웨어 행 참조. 페이지에 없는 항목은 "미확인"으로 표기.

## 비고(미확인)
페이지가 중국어여서 번역 과정 오차 가능, 중간 신뢰도. 표 15개 항목 중 '미확인' 시작 항목 1개.
