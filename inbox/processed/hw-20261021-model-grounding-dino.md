## 핵심 사양 (초록)
- DINO 검출기 + grounded pre-training. 카테고리 이름이나 지칭 표현(referring expression)으로 지정한 객체 검출.
- 구성: feature enhancer, language-guided query selection, cross-modality decoder.
- COCO 제로샷 전이 52.5 AP(COCO 학습 데이터 없이), ODinW 제로샷 평균 26.1 AP('sets a new record').
- 제출 2023-03-09, v5 2024-07-19.
