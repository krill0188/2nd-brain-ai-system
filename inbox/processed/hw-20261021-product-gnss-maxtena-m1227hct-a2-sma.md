# Maxtena M1227HCT-A2-SMA

출처 유형: 제조사 데이터시트 PDF(유통사 Farnell 호스팅 사본, Ordering Part # 100-00004-02). maxtena.com에서는 GNSS 제품 URL을 못 찾아 유통사 사본으로 대체.

## 핵심 사양 (출처 페이지에 적힌 값만)

| 항목 | 값 |
|---|---|
| 지원 대역 | L1 (1565~1610 MHz), L2 (1217~1250 MHz) — GPS, GLONASS (L5 미지원 표기) |
| 편파 | RHCP |
| 수동 peak 이득 | 2 dBic @1227 MHz, 2 dBic @1575 MHz (typ.) |
| 총 이득 | 30 dBic @1227 MHz / 28 dBic @1575 MHz / 28 dBic @1602 MHz (typ.) |
| 축비 | 0.5 dB typ. / 1 dB max |
| 잡음지수 | 1.5 dB typ. |
| 입력 전압 | 3 ~ 12 V |
| 소비 전류 | 25 mA typ. |
| 무게 | 24 g (typical, "Ultra light weight") |
| 크기 | 도면 치수만 있고 본문 수치 미확인 |
| 커넥터 | 일체형 SMA(screw-on) |
| 방수·온도 | IP-67, -40 ~ 85 °C |
| 기타 | Out-of-band rejection > 50 dB, 50 V/m out-of-band 간섭 정격, ground plane independent, Helicore 기술 |

## 용도
RTK/GIS·정밀항법용 L1/L2. 드론 용도는 이 문서에 명시되지 않음(Military & security 등 나열).

## 호환·인터페이스
SMA 직결 스크루온 방식.

## 비고(미확인)
L5 미지원, 직경·길이 수치 이 PDF 텍스트에서 미확인. 24 g 은 가벼우나 드론 적합성 판단은 하지 않음.
