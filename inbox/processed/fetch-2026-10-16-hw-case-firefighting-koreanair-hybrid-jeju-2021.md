# 대한항공 하이브리드 드론 - 제주도 소방 감시 운용

## 개요

대한항공이 제주도 소방 당국에 납품한 하이브리드 엔진 방식 감시 드론. 배터리 전용 드론(30분)의 체공 한계를 극복하기 위해 하이브리드 동력계를 적용. 2021년 도입 확인(아시아경제 보도). 한국 공공 안전 분야 드론 도입의 초기 대표 사례.

## HW 구성 (표)

| 항목 | 수치 | 출처 신뢰도 |
|------|------|------------|
| 동력 방식 | 하이브리드 엔진 | 높음(아시아경제) |
| 최대 체공 시간 | 최대 2시간 (배터리 전용 대비 4배) | 중간(언론 보도) |
| 최대 비행 고도 | 500 m | 중간 |
| 순항 속도 | 72 km/h | 중간 |
| 운용 온도 | -20°C ~ 45°C | 중간 |
| 최대 바람 저항 | 14 m/s | 중간 |
| 탑재 센서 | EO(전자광학) + IR(적외선) 카메라 | 높음 |
| 모터·프로펠러 세부 사양 | 미확인 | — |
| 배터리 사양 | 미확인 | — |
| 기체 중량 | 미확인 | — |

## 성과·한계

- 하이브리드 동력 적용으로 배터리 전용 대비 **4배 체공 시간** 달성.
- EO+IR 센서로 야간·연기 속 화재 탐지 가능.
- 제주도 화산지형 특성(해발 고도 변화)에 적합한 500m 운용 고도.
- **한계:** 모터/엔진 하이브리드 구성 세부 사양 비공개. 운용 실적(임무 수, 감지 건수) 비공개. 현재 운용 상태(2026 기준) 미확인.

## 출처의 신뢰도

- 아시아경제 영문판 보도 (Tier 2): **중간** — 언론 보도, 기술 상세는 대한항공 공식 자료로 교차 확인 권고
- 확인 날짜: 2026-10-16
